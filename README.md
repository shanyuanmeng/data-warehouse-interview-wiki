# 数仓面试知识库

面向数据仓库工程师面试准备的中文知识库，包含体系化学习章节、概念速览和专项面试题库。

## 主要内容

- [多模态数据工程实习经验总结](./多模态数据工程实习经验总结.html)：整合 24 份项目材料与 16 张流程图，包含项目梳理、Coverage 案例、能力解读、面试叙事和完整原文附录
- 数仓分层与维度建模
- Hadoop / HDFS
- Hive 与 SQL
- Spark、Flink、Kafka
- 数据库与计算机基础
- 数据治理、调度与项目场景题
- 75 道面试问答，支持简短版与结构化详细版切换
- 收藏、复习进度、搜索和随机练习

## 本地使用

直接打开 `数仓面试知识库.html`，或在项目目录启动本地服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/数仓面试知识库.html
```

复习状态与收藏保存在浏览器的 `localStorage` 中。

## 内容说明

面经内容用于识别高频考点，答案经过重新组织。涉及组件行为、参数和工程方案时，建议结合实际版本、数据规模与业务约束理解适用条件。用户提供的原始参考资料仅保存在本地，不纳入仓库。
